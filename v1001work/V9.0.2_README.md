# Baby V9.0.2 — Live Agent Routing

Fixes the live V9 routing defect where a healthy NVIDIA/Nemotron provider could still fall into the V8 deterministic copilot after planner parsing failed.

## Root cause fixed
V9.0.1 extracted fenced planner JSON with a non-greedy regex. Planner JSON is nested (`entities`, `tool_calls`, `args`, `state_updates`), so the parser could truncate at the first inner `}`. The provider call itself succeeded, leaving provider status AGENTIC, while `Copilot.ask()` caught the parser failure and silently used legacy fallback.

## Changes
- balanced/decoder-based JSON extraction for nested and fenced Nemotron planner output
- planner schema normalization/validation
- healthy AUTO/AGENTIC requests cannot silently enter legacy path
- successful agentic calls clear stale fallback state
- runtime response includes AGENTIC/fallback metadata
- provider status includes safe `last_trace` diagnostics (no secrets)
- regression tests reproduce nested planner output and the exact healthy-live routing invariant
- AI scoring authority remains 0%; chat execution authority NONE; real-money execution DISABLED
