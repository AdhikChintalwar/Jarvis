# BABY V10.0.3 — Trade Eligibility & Execution-Data Hardening

V10.0.3 closes the trade-quality gap found by the cross-stock V10.0.2 test.

## New hard gates

- Active setup is revalidated against the current quote.
- T1 and T2 risk/reward must satisfy configurable deterministic floors.
- Default floors: T1 >= 1.0R and T2 >= 2.0R.
- Targets must be above a long entry and invalidation must remain below entry.
- Current paper-entry evidence must be execution-grade.
- Alpaca IEX is the preferred independent current-state source.
- yfinance remains secondary/prototype research/reference data and cannot authorize a paper entry.
- Invalid, crossed, excessively wide, or stale quotes cannot authorize a paper entry.
- A blocked proposal exposes no actionable proposed quantity/notional.
- Hard-risk overrides retain precedence.
- Proposal remains separate from execution; real-money execution remains disabled.

## Configuration

```bash
BABY_MIN_RR_TARGET_1=1.0
BABY_MIN_RR_TARGET_2=2.0
BABY_EXECUTION_QUOTE_MAX_AGE_SECONDS=180
BABY_EXECUTION_MAX_SPREAD_PERCENT=2.0
```

These are explicit policy defaults, not claims of optimality. They should be validated in historical/out-of-sample work before strategy optimization.

## Proposal states

- `ELIGIBLE`: every deterministic gate passed.
- `WAITING`: no current entry setup.
- `RESEARCH_SETUP_ONLY`: setup exists but current market evidence is not execution-grade.
- `BLOCKED`: risk, trade quality, decision, coverage, structure, or sizing gate failed.

## Authority

- AI scoring authority: 0%
- AI execution authority: NONE
- Real money: DISABLED
