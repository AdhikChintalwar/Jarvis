# Baby V10.1–V10.6 Unified Intelligence Release

This release layers six deterministic/evidence-first intelligence stages on top of the stable V10.0.3 research/trade safety boundary.

- V10.1 SEC/XBRL fundamentals: revenue, annual revenue growth, margins, net income, OCF, CapEx, FCF, cash, debt, net cash, assets/liabilities/equity. Primary values carry SEC concept/form/accession/filing metadata when available.
- V10.2 technical/volume/market structure: deterministic trend regime, RSI, ATR%, RVOL/volume regime, production support/resistance. It does not invent levels.
- V10.3 news/catalyst/events: structured attributed news events with timestamps/source and explicit `causality=NOT_ESTABLISHED`.
- V10.4 macro/sector/cross-asset: production macro score, sector/industry, SPY/QQQ context when available. Missing inputs remain UNKNOWN.
- V10.5 valuation/expectations: P/E, P/S, FCF yield and a deterministic reverse-DCF implied growth scenario. Yahoo/yfinance profile values are SECONDARY only; SEC remains primary for company facts.
- V10.6 institutional/options/order-flow: typed fields for put/call, IV, institutional ownership, short interest and flow. If no verified feed is configured, these remain UNKNOWN; price action is never used to fabricate them.

## Authority
AI scoring authority: 0%. AI execution authority: NONE. Real-money execution: DISABLED. Existing V10.0.3 hard-risk, R:R and execution-grade quote gates are unchanged.
