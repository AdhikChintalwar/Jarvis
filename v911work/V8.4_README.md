# BABY V8.4 — Decision → TradePlan → Paper Proposal

V8.4 connects Baby's production deterministic investment system to the persistent forward paper broker.

## Production path
`StockAnalyzer evidence -> BabyInvestmentSystem -> DecisionEngine + ValidationEngine + TradePlanAgent -> UI research record -> PaperProposalService -> PENDING paper order -> explicit EXECUTE PAPER -> simulated fill`

A CANDIDATE/WATCH decision alone is never sufficient. A new-long proposal requires a production trade setup of `AT_PULLBACK_ZONE` or `BREAKOUT_TRIGGERED`, no sovereign hard/unified-risk block, usable quote evidence, valid entry/invalidation structure, sufficient evidence coverage, and a positive position size under paper-account cash/equity constraints.

Defaults: 0.5% account risk budget and 10% max position, multiplied by the production unified-risk multiplier. Configure with `BABY_PAPER_RISK_PERCENT` and `BABY_PAPER_MAX_POSITION_PERCENT`.

The proposal endpoint cannot execute a fill. Creating a proposal order creates only a `PENDING` simulated order. The existing separate `EXECUTE PAPER` action is required. Brokerage connection remains NONE and real-money execution remains DISABLED.
