# BABY V8.7.4 — Router + Knowledge Resilience

Hardens the V8.7.3 Ask Baby router against the two failures found in live UI testing.

- Typo-tolerant conversational quote continuation (`howb about Tesla stock`).
- Explicit new company/entity continues the quote workflow instead of falling into stale AAPL UI evidence context.
- Canonical educational topic IDs (`SEC` / `SEC filings` -> `SEC_FILINGS`).
- Safe educational lookup for TOPICS, status terms and abbreviations; follow-ups cannot raise a topic KeyError.
- Deterministic SEC-filings education for overview, deeper explanation, importance, interpretation and examples.
- Existing RSI multi-turn context and Alpaca PAPER/AI authority constraints remain unchanged.

This release does not grant chat order authority, AI scoring authority, or real-money execution.
