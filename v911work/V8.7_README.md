# BABY V8.7 — Explainable Research + Ask Baby + Alpaca Paper

V8.7 combines the V8.6 Alpaca PAPER execution bridge with the explainability/copilot phase.

## Added
- Global **Ask Baby** research copilot drawer.
- Deterministic natural-language price filter: e.g. `show stocks between $10 and $20`.
- Alpaca active-asset master list + batched IEX snapshots for price filters.
- Context-aware Research questions (`Why is AAPL WATCH?`, `Explain this stage`).
- Optional Nemotron only for general educational language; it has no scoring/execution authority.
- Complete Research Legend and per-stage **Explain this stage** panels.
- Status and abbreviation legends.
- Human-readable Trade Plan visualization; raw JSON moved under Advanced.
- Alpaca PAPER remains integrated; eligible production proposals can be explicitly submitted with `EXECUTE ALPACA PAPER`.

## Authority
- AI scoring authority: 0%
- AI execution authority: NONE
- Alpaca environment: PAPER only
- Real-money execution: DISABLED
- Market filters are deterministic tool calls, not LLM-generated stock lists.

## Market-data note
Paper/basic Alpaca access uses IEX for the V8.7 broad price filter. It is not full SIP coverage. The UI/API reports the feed explicitly.
