# Baby V9.0.1 — Runtime Hardening

V9.0.1 makes the agentic copilot fail-safe. NVIDIA 401/403/404/429, timeout, network, and invalid-response failures degrade to the deterministic V8.7.4 copilot instead of crashing chat.

## Runtime modes
- `BABY_COPILOT_MODE=AUTO` (default): prefer agentic; fall back safely.
- `BABY_COPILOT_MODE=AGENTIC`: prefer agentic but still fail safe.
- `BABY_COPILOT_MODE=LEGACY`: deterministic copilot only.

Optional provider configuration:
- `NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1`
- `NVIDIA_MODEL=nvidia/nemotron-3-ultra-550b-a55b`
- `BABY_AGENT_TIMEOUT_SECONDS=30`
- `BABY_AGENT_CIRCUIT_SECONDS=60`

`GET /api/copilot/status` reports AGENTIC, DEGRADED, or LEGACY and provider diagnostics without exposing secrets.

Authority remains unchanged: AI scoring 0%, chat execution NONE, real-money execution DISABLED.
