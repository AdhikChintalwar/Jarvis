# Baby V9.1 — Multi-Provider Agentic Brain

Provider-independent agentic copilot. Default provider order: OpenAI → NVIDIA → deterministic Baby fallback.

## Environment

Required for OpenAI:

    OPENAI_API_KEY=...

Optional:

    OPENAI_MODEL=gpt-5.6-luna
    OPENAI_BASE_URL=https://api.openai.com/v1
    BABY_AI_PROVIDER_ORDER=OPENAI,NVIDIA
    BABY_COPILOT_MODE=AUTO
    BABY_AI_TIMEOUT_SECONDS=45
    BABY_AI_FAILURE_THRESHOLD=1
    BABY_AI_CIRCUIT_SECONDS=60

NVIDIA remains supported through NVIDIA_API_KEY/NVIDIA_MODEL/NVIDIA_BASE_URL.

OpenAI/NVIDIA are conversation and research-planning providers only. They have 0% Baby scoring authority and no execution authority. Current facts remain tool/evidence grounded.
