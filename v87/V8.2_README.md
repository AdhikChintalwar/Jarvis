# BABY V8.2 — Control Center Integration

V8.2 connects the V8 cockpit to locally persisted Baby subsystems without changing investment decisions.

## Connected surfaces
- Dashboard: subsystem availability and safety authority.
- Markets: latest locally persisted scanner JSON; click a symbol to open Research.
- Research: V8.1 production StockAnalyzer integration.
- Portfolio: read-only view of local paper-trading SQLite data. Real-money execution remains disabled.
- Backtests: loads `data/v7_5_real_investment_test.json` and exposes performance, benchmark and audit evidence.
- Alerts: existing V8 alert/notification store.
- Automations: read-only view of `data/baby_automations.db`.

Adapters are deliberately tolerant of unavailable stores. Missing subsystem data is reported NOT_AVAILABLE rather than fabricated.

## Safety/integrity
AI scoring authority: 0%. AI execution authority: 0%. Real-money execution: DISABLED.
