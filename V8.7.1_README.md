# BABY Investor V8.7.1 — Copilot Context + Alpaca Paper Hardening

V8.7.1 is a hardening release over V8.7.

- Ask Baby now keeps a server-side conversation session for active topic, symbol, stage and deterministic filter context.
- Pronoun/deictic follow-ups such as `Give me brief about it`, `How is it calculated?`, and `Why is this so low?` resolve against active context.
- RSI/ATR/SMA/EMA/FCF have deterministic educational explanations; stock-specific facts still come from Baby evidence/tools.
- Alpaca broker explicitly loads project `.env` and remains hard-coded to PAPER mode.
- Local SQLite simulator and Alpaca Paper are visually and operationally separated.
- Research-driven Alpaca proposal uses current Alpaca PAPER equity/cash and is recomputed server-side at submission time.
- Browser quantity is ignored by the research-driven Alpaca route.
- WAIT/AVOID/hard-risk/untriggered trade setups remain blocked.
- Ask Baby cannot execute orders. AI scoring authority remains 0%. Real-money execution remains disabled.

The generic manual Alpaca Paper ticket remains available for explicit broker testing, clearly labeled as a manual simulated-paper path. Normal Baby investing should use Research → Trade Plan → Alpaca Paper Proposal.
