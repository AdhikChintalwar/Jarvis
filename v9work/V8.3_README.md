# BABY V8.3 — Persistent Forward Paper Trading

V8.3 adds a persistent forward-only paper account. It is separate from V7.5 historical backtesting.

- Auto-creates `data/baby_paper_trading.db` when the UI API starts.
- Normalized account, positions, orders, fills, and equity-snapshot tables.
- Average cost, realized and unrealized P&L.
- Market and limit paper orders.
- Configurable slippage and fee assumptions.
- Stores quote source, quality, and as-of time with every fill.
- Missing position marks remain UNKNOWN; they are never silently valued at zero.
- Paper orders start PENDING and require explicit simulated execution from the UI/API.
- No brokerage API exists. Real-money execution remains disabled.

Environment options:
`BABY_PAPER_STARTING_CASH=100000`
`BABY_PAPER_SLIPPAGE_BPS=5`
`BABY_PAPER_FEE_BPS=0`
