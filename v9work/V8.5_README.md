# BABY V8.5 — Strict Production Investment Integration

V8.5 removes the loose Decision/TradePlan UI compatibility guesses and binds the cockpit to the actual production contracts:

`StockAnalyzer -> BabyInvestmentSystem.evaluate(report, history, account_size) -> DecisionEngine + ValidationEngine + TradePlanAgent -> strict production contract -> UI -> paper proposal gate`

## Fixes

- Maps `DecisionReport.research_state`, `evidence_confidence`, and `evidence_coverage` correctly.
- Maps Unified Risk `risk_level`, `risk_score`, and `hard_overrides` correctly.
- Maps `TradePlanV47.status/current_setup/pullback/breakout/position` correctly.
- Empty Decision/Validation/TradePlan packets can no longer silently masquerade as valid production output.
- A production contract failure makes the research job fail with an explicit error.
- Trade plan absence below 50 OHLC rows is explicitly `NOT_PRODUCED`.
- Fixes `BabyInvestmentSystem` threshold from 30 to 50 OHLC rows to match `TradePlanAgent`.
- Paper proposal remains gated by a triggered deterministic setup and Unified Risk.
- `TOP_RESEARCH` is recognized as a research state, but still requires a triggered trade setup; research state alone never creates an order.
- Real-money execution remains disabled. AI scoring/execution authority remains 0.

After installing V8.5, force-refresh old research snapshots because V8.4 JSON used incorrect UI field mappings.
