# Baby Investor V8.7.2 — Conversation Engine Hardening

This patch hardens Ask Baby after real UI testing exposed a generic-continuation failure (`What is RSI?` → `Explain more`).

## Changes
- General continuation resolver, not RSI-specific routing.
- Persists `active_topic`, visible UI symbol/stage, active filter, and previous intent per chat session.
- Handles: Explain more, Tell me more, Go deeper, Give me more details, How is it calculated?, Why is it important?, Give me an example, Is it good or bad?, and pronoun/deictic variants.
- Explicit topic switches replace the previous topic and persist across later turns.
- Added richer deterministic knowledge for RSI, ATR, SMA, EMA, FCF and P/E.
- Visible research-stage context remains authoritative when there is no active educational topic.
- Nemotron remains explanation-only and receives active-topic context only after deterministic routing.
- No change to scoring authority (0%), execution authority (NONE), Alpaca PAPER-only boundary, or real-money disabled boundary.
