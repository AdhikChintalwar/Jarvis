# Baby Investor V8.7.3 — Intent + Entity Routing

Hardens Ask Baby so explicit current-market requests override stale UI/conversation context.

## Routing precedence
1. Explicit current quote / explicit company or ticker
2. Explicit deterministic tool/filter request
3. Active conversational topic
4. Current UI symbol/stage
5. Education fallback

## Current quotes
- Company names and tickers resolve against Alpaca active US equities, with conservative aliases for common names.
- Current quote path uses Alpaca Market Data snapshots and reports feed, timestamp and quality.
- IEX is labeled as IEX and is never represented as consolidated SIP.
- An explicit new company updates active symbol and clears stale stage/topic context.
- Follow-ups such as `what about AMD?` retain quote intent and switch entity.

## Authority
AI scoring authority remains 0%. Ask Baby has no execution authority. Real-money execution remains disabled. Alpaca order submission remains PAPER-only behind the existing explicit confirmation gate.
