# BABY V8.1 — Production Research Integration

V8.1 connects the Research UI to the local production `investor.StockAnalyzer`.

## Flow
Search ticker -> check persisted UI research -> Run full Baby research -> background production StockAnalyzer -> auditable UI projection -> persisted JSON -> notification -> UI auto-refresh.

Quotes remain a separate faster data plane. yfinance fallback is conservatively labelled DELAYED; it is never labelled LIVE unless an injected provider explicitly declares LIVE.

## Run
```bash
source .venv/bin/activate
pip install -r requirements-v8.txt
python -m uvicorn baby_ui_backend.app:app --host 127.0.0.1 --port 8787 --reload
```
Second terminal:
```bash
cd frontend
npm install
npm run dev
```
Open http://127.0.0.1:5173 and search AAPL. If no report exists, click **Run full Baby research**.

## API
- GET `/api/research/AAPL` — returns READY report or NOT_RESEARCHED state
- POST `/api/research/AAPL/run` — start production research
- POST `/api/research/AAPL/run?force=true` — refresh research
- GET `/api/research/AAPL/status` — background job status
- WS `/ws/market/AAPL` — independent quote updates

No UI code changes the deterministic investment score. Real-money execution remains disabled.
