# Baby V10.0.1 — Consistency Hardening

V10.0.1 preserves the V10 architecture and tightens contracts discovered in the AAPL full-flow live test.

- Adds one explicit V10 `market_snapshot` for current-state gates while preserving the immutable production trade-plan research price and source separately.
- Inactive setups now expose `WAIT_FOR_VALID_ENTRY` with no active entry, stop, targets, or R:R. Scenario levels remain visible only in the production trade plan.
- Paper proposal reason precedence no longer lets a missing quantity overwrite the real reason that the setup has not triggered.
- Scored stages whose exported metrics contain no reconstructable evidence are marked `EVIDENCE_LINEAGE_INCOMPLETE`; the production score/status are preserved rather than silently discarded.
- Existing paper orders are explicitly classified as pre-existing and not created by the read-only V10 full-flow request.
- Proposal remains read-only. AI scoring authority is 0%, AI execution authority NONE, real-money execution DISABLED.
