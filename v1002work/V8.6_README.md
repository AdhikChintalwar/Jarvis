# BABY Investor V8.6 — Alpaca Paper Execution Bridge

V8.6 adds a real external broker integration, but **PAPER ONLY**.

## Safety boundary
- `AlpacaPaperBroker` always creates Alpaca `TradingClient(..., paper=True)`.
- There is no live broker endpoint in the V8.6 backend.
- Every Alpaca paper order requires the exact confirmation phrase `EXECUTE ALPACA PAPER`.
- Research never directly submits an order. The production paper proposal is recomputed immediately before broker submission.
- AI scoring authority remains 0%. AI execution authority remains NONE.

## Environment
Add to `.env` (do not commit the file):

```
ALPACA_PAPER_API_KEY=...
ALPACA_PAPER_SECRET_KEY=...
```

Install:

```
pip install -r requirements-v8.txt
```

## Test

```
python v8_6_contract_test.py
./run_v8.sh
```

Then open Portfolio → Alpaca Paper. The status endpoint can verify the connection without placing an order.
