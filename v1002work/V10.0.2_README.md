# BABY V10.0.2 — Auto Research Orchestration

V10.0.2 removes the pre-research requirement from the full investment flow.

## Contract

- Missing research -> production StockAnalyzer is run and persisted.
- Fresh research -> reused.
- Stale research -> refreshed.
- Concurrent research -> waits on the existing ResearchService job rather than inventing a second score.
- Failure -> explicit `RESEARCH_FAILED`; never a screen full of silent nulls.
- One current quote snapshot feeds the current-state gate and paper proposal.
- Production trade levels remain immutable research outputs.
- Inactive setup -> no active entry, stop, targets, quantity, or paper order.
- GET full-flow remains backward compatible and auto-researches by default.
- POST `.../run-full-flow` is the canonical endpoint because research refresh mutates the cache.

Default research freshness: 6 hours (`BABY_RESEARCH_MAX_AGE_SECONDS=21600`).
Default synchronous orchestration timeout: 240 seconds (`BABY_RESEARCH_TIMEOUT_SECONDS=240`).

Real-money execution remains disabled. AI scoring authority remains 0%.
